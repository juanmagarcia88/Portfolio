Proyectos

Aquí voy a mostrar algunos de los proyectos en los que voy a trabajar. Cada uno va a reflejar lo que voy aprendiendo y cómo aplico mis conocimientos en el desarrollo web tanto en Front-end como en Back-end.

Web de Reservas del Hotel Casa Azul

Este proyecto fue desarrollado durante mi curso de 2º DAW. Se trata de una aplicación web para simular reservas de habitaciones en un hotel de mi pueblo, Andújar. Los usuarios pueden registrarse, iniciar sesión, realizar reservas según fechas y tipos de habitaciones, y consultar o eliminar sus reservas desde su área personal. El administrador puede visualizar y gestionar todas las reservas.

  • Front-end: Vue.js
  • Back-end: Spring Boot
  • Base de datos: MySQL

Aprendí muchísimo desarrollándolo: integración entre frontend y backend, gestión de usuarios y autenticación, y comunicación con base de datos. Fue un proyecto grande que me ayudó a afianzar muchos conocimientos.

También implementé responsive y adapté toda la web a cualquier tamaño de pantalla.

Pokédex

Este proyecto consiste en una Pokédex desarrollada en React donde consumo la API pública de Pokémon para mostrar información detallada de cada uno. La aplicación permite buscar Pokémon por nombre, filtrarlos por tipo, visualizar sus estadísticas al hacer click en su carta y gestionar una lista de favoritos personalizada.

  • Front-end: React
  • Herramientas: Vite
  • API: PokeAPI
  • Almacenamiento: LocalStorage

Con este proyecto he mejorado bastante mi manejo de React, especialmente en el uso de hooks, gestión de estado y consumo de APIs. También he trabajado el manejo del localStorage para guardar los Pokémon favoritos del usuario y mantenerlos durante la sesión. Además, he reforzado conceptos como el filtrado dinámico, renderizado de listas y organización de componentes en una aplicación real.

La aplicación es totalmente responsive y está adaptada a diferentes tamaños de pantalla, ofreciendo una buena experiencia tanto en móvil como en escritorio.
